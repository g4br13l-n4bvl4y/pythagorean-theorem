# Pythagorean Program

## Description
A program that calculates the hypotenuse of a triangle using the Pythagorean Theorem.
## How to Run
- From the repo, download the corresponding file.
- Open a valid Python IDE (preferably PyCharm)
- Click the file (either in File Explorer or opened in PyCharm) and hit the run (▶) button.
- And watch the magic!
## Input Needed
Inputs should be `a` and `b` (measurement of the legs)
## Sample Output
Input 1: `Enter the length for side a: 3` (inputs `a`)\
Input 2: `Enter the length for side b: 4` (inputs `b`)\
Output: `The hypotenuse is 5.00`
